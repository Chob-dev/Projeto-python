Descrição do Projeto
EletroSafe é um sistema desenvolvido em Python para auxiliar usuários no monitoramento e planejamento do consumo de energia elétrica residencial. O sistema permite cadastrar equipamentos elétricos, calcular o consumo mensal estimado, simular o valor da conta de energia, analisar a corrente elétrica da instalação e sugerir o disjuntor adequado, além de gerar relatórios em arquivo texto.
Funcionalidades
    • Cadastro de equipamentos elétricos
    • Listagem e remoção de equipamentos
    • Cálculo do consumo mensal de energia
    • Análise e recomendação de disjuntor
    • Simulação da conta de energia elétrica
    • Geração de relatórios
Conceitos e Estruturas Utilizadas
    • Variáveis e tipos de dados
    • Estruturas condicionais (if, elif, else)
    • Estruturas de repetição (for e while)
    • Funções
    • Listas
    • Dicionários
    • Manipulação de strings
    • Manipulação de arquivos texto
    • Entrada e saída de dados
    • Cálculos matemáticos aplicados ao consumo de energia
Como Executar
Execute o arquivo Python principal e utilize o menu interativo para acessar as funcionalidades do sistema.
